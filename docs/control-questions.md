# Ответы на контрольные вопросы

## 1. Какие основные типы данных используются в Python?

`int`, `float`, `str`, `bool`, а также `NoneType`. Для наборов данных используются `list`, `tuple`, `dict`, `set`.

## 2. Чем отличаются int, float, str и bool?

`int` хранит целые числа, `float` — числа с плавающей точкой, `str` — текст, `bool` — логические значения `True` и `False`.

## 3. Для чего используется преобразование типов?

Для получения значения нужного типа: например, `int("14")` превращает текст в число для расчётов. Некорректное преобразование вызывает ошибку.

## 4. Какие операции можно выполнять со строками?

Конкатенацию `+`, повторение `*`, сравнение, поиск через `in`, индексацию и срезы; методы `strip()`, `replace()`, `lower()`; форматирование f-строками.

## 5. Какие операторы сравнения используются в Python?

`==`, `!=`, `<`, `>`, `<=`, `>=`. Они сравнивают значения; `is` проверяет идентичность объектов.

## 6. Для чего используется конструкция if?

Для выполнения блока кода, только если условие истинно.

## 7. В чём различие между if, elif и else?

`if` задаёт первую проверку, `elif` — следующую при ложности предыдущих, `else` — случай, когда ни одно условие не выполнено.

## 8. Как записываются составные условия?

С помощью `and`, `or`, `not` и скобок: `not is_busy and start_hour >= 10`.

## 9. Для чего нужны and, or и not?

`and` требует истинности обоих условий, `or` — хотя бы одного, `not` меняет логическое значение на противоположное. `and` и `or` используют сокращённое вычисление.

## 10. Что такое модуль Python?

Единица организации кода со своим пространством имён; обычно файл `.py`, содержащий определения и инструкции.

## 11. Для чего используется import?

Для подключения модуля и использования его возможностей.

## 12. Чем отличаются способы импорта?

`import datetime` даёт обращение `datetime.date.today()`, а `from datetime import date` — `date.today()`. Второй способ связывает выбранное имя в текущем пространстве имён.

## 13. Для чего используется виртуальное окружение?

Для изоляции зависимостей и их версий между проектами. Создаётся командой `python3 -m venv .venv`.

## 14. Что такое IDE?

Интегрированная среда разработки: редактор, запуск, навигация по коду и отладчик. Например, PyCharm; VS Code получает соответствующие возможности через расширения.

## 15. Для чего используется Git?

Для сохранения версий, просмотра изменений, работы с ветками и совместной разработки. GitHub — сервис размещения репозиториев, а Git — система контроля версий.

## 16. Что такое репозиторий?

Хранилище проекта и истории изменений. Локальный Git-репозиторий хранит служебные данные в `.git`.

## 17. Что такое commit?

Зафиксированное состояние проекта с автором, сообщением и ссылками на предшествующие коммиты. Перед коммитом изменения добавляют в индекс командой `git add`.

## 18. Для чего нужен .gitignore?

Чтобы Git не предлагал добавлять указанные неотслеживаемые файлы: окружение, кэш, секреты. Уже отслеживаемые файлы он автоматически не удаляет.

## 19. Для чего нужен README.md?

Для описания назначения, запуска, функций, структуры и плана развития проекта.

## 20. Что такое отладка?

Поиск причин неправильного поведения программы через анализ выполнения и состояния переменных.

## 21. Что такое breakpoint?

Точка останова, в которой отладчик приостанавливает выполнение перед инструкцией.

## 22. Зачем нужно пошаговое выполнение?

Чтобы наблюдать порядок операций и изменения переменных. Step Over выполняет вызов целиком, Step Into входит внутрь функции.

## 23. Какую задачу решает приложение?

Проверяет возможность записи клиента в барбершоп, рассчитывает стоимость и формирует результат записи.

## 24. Кто является пользователем?

Клиенты, мастера и администраторы барбершопа.

## 25. Какие сущности выделены?

Клиент, мастер, услуга и запись. Запись связывает клиента, мастера, услугу и время.

## 26. Какие функции планируется реализовать?

Управление услугами и расписанием, создание и отмена записей, личный кабинет клиента, администрирование и API.

## 27. Какой сценарий реализован сейчас?

Для одной записи проверяется дата и свободное время, рассчитывается скидка студента и выводится подтверждение либо причина отказа.

## 28. Какие конструкции Python использованы?

Простые типы, присваивание, преобразования типов, арифметика, сравнения, логические операторы, ветвления, функции, импорт и f-строки. Для отрицательной цены предусмотрен `ValueError`.

## 29. Что добавится после ООП и Django?

Классы сущностей, Django-модели и связи, база данных, представления, шаблоны, формы, регистрация и права доступа.

## 30. Почему тема подходит для веб-приложения?

Несколько ролей работают с общими данными; нужны хранение записей, проверка расписания, формы, авторизация и одновременный доступ через браузер.
