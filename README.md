# Barber Booking — запись в барбершоп

Учебный индивидуальный проект. Практическая работа № 1: «Основы Python:
актуализация знаний и настройка рабочего окружения».

## Назначение

Сервис помогает клиенту выбрать услугу и время визита, узнать стоимость
и получить подтверждение записи. На ПР1 реализован консольный прототип
для одной записи с заранее заданными данными.

## Целевая аудитория

Клиенты барбершопа, мастера и администраторы салона.

## Предметная область

Барбершоп работает с 10:00 до 20:00. Услуга занимает определённое время.
Запись допустима, если дата не прошла, время свободно и услуга полностью
помещается в рабочие часы. Студентам предоставляется скидка 10%.
Цены и правила скидок — учебные условия этого проекта.

## Основные сущности

- Клиент: имя, контактные данные, признак студента.
- Мастер: имя, специализация, рабочее расписание.
- Услуга: название, цена, продолжительность.
- Запись: клиент, мастер, услуга, дата, время и статус.

На ПР1 данные представлены простыми переменными. Модели и хранение
нескольких записей появятся на следующих этапах.

## Основные функции

В `main.py` реализованы три функции предметной области:

1. `is_slot_available(...)` проверяет дату, занятость и рабочие часы.
2. `calculate_price(...)` рассчитывает стоимость с учётом скидки студента.
3. `get_booking_status(...)` подтверждает или отклоняет запись,
   в том числе при пустом имени клиента.

`main()` объединяет их в законченный сценарий: проверка времени →
расчёт цены → вывод результата записи. Использованы `str`, `int`, `float`,
`bool`, преобразования типов, арифметика, сравнения, ветвления, функции
и импорт `date` из `datetime`. В основном сценарии нет классов и циклов.

## Запуск

Требуется Python 3.10 или новее. Приложение использует стандартную библиотеку.

```bash
python3 -m venv .venv
source .venv/bin/activate
python main.py
```

Windows PowerShell: вместо `source` выполните `.venv\Scripts\Activate.ps1`.

Демонстрационные данные задаются в `main()`: клиент Алексей, стрижка,
сегодняшняя дата, 14:00–15:00, цена 1500 рублей, студент, слот свободен.
Результат: стоимость 1350 рублей и подтверждение записи.
Для другого сценария измените переменные в `main()`.

Прототип не сохраняет запись, не проверяет реальное расписание и текущее
время внутри дня. Признак занятости задаётся вручную. Проверка относится
к календарной дате, а не к уже прошедшему часу сегодня.

## Проверки

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
python -m pycodestyle main.py tests/test_main.py
```

Без внешних зависимостей: `python -m unittest discover -s tests -v`.
Тесты проверяют скидку, обычную цену, округление, неправильную цену,
занятый слот, прошедшую и будущую даты, границы рабочего дня и имя клиента.
Коллекции и классы используются только в тестовом коде.
