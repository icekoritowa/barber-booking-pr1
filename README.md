# Barber Booking — запись в барбершоп

Индивидуальный сквозной проект по дисциплине «Технологии разработки
приложений на базе фреймворков». Текущий этап: **ПР2**.
[Репозиторий](https://github.com/icekoritowa/barber-booking-pr1).
Название репозитория сохранено с ПР1, история разработки продолжается.

## Назначение и аудитория

Консольное приложение для каталога услуг и записи клиентов к одному мастеру.
Целевая аудитория будущего веб-приложения — клиенты, мастера и администраторы.
Основные сущности: услуга, запись, клиент и мастер. На ПР2 услуги представлены
словарём, записи — списком словарей; имя клиента хранится в записи,
мастер пока один. Пользовательские классы не используются.

## Возможности ПР2

1. Просмотр и добавление услуг с ценой и длительностью.
2. Поиск по подстроке без учёта регистра.
3. Отбор по бюджету с генератором и сортировка с `lambda`.
4. Проверка свободного времени по всем активным записям.
5. Создание записи и расчёт скидки студента 10%.
6. Отмена записи с сохранением истории и освобождением времени.
7. Просмотр записей, включая отменённые.
8. Статистика: количество записей, уникальные имена активных клиентов,
   сумма стоимости активных записей (это не фактически полученная выручка).
9. Загрузка JSON при запуске, сохранение после каждого изменения.
10. Обработка ошибок ввода, неверных дат, повреждённых файлов и ошибок записи.

### Преемственность ПР1

`calculate_price`, `get_booking_status` и `is_slot_available` перенесены
из `main.py` в `bookings.py` и используются новым сценарием.
Исходная демонстрация доступна через `python main.py --demo` или пункт 11
меню: стрижка 1500 рублей, скидка 10%, итог 1350 рублей.
Демонстрация работает на отдельных коллекциях и не меняет файлы пользователя.
Материалы ПР1 остались в `docs/` как история; текущие материалы — `docs/pr2/`.

## Установка и запуск

Python 3.10+. Программа использует стандартную библиотеку, pytest и flake8
нужны только для разработки.

```bash
git clone https://github.com/icekoritowa/barber-booking-pr1.git
cd barber-booking-pr1
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

В PowerShell вместо `source` выполните `.venv\Scripts\Activate.ps1`.
При необходимости используйте `python` вместо `python3`.

Данные по умолчанию находятся рядом с `main.py` в `data/`, независимо от
текущего рабочего каталога. Можно указать отдельный каталог:

```bash
python main.py --data-dir ./my-data
```

При отсутствии файлов каталог и записи пусты: добавьте услугу через пункт 2.
Поставляемый `data/services.json` содержит три примера услуг;
`data/bookings.json` пуст, реальные персональные данные не публикуются.

### Пример сценария

- Пункт 1: посмотреть ID услуг.
- Пункт 7: ID `1`, сегодняшняя или будущая дата `ГГГГ-ММ-ДД`, час `14`,
  имя `Анна`, признак студента `да`. Стоимость — 1350 рублей.
- Пункт 6 с тем же временем: слот недоступен.
- Пункт 9: посмотреть номер созданной записи.
- Пункт 8: отменить запись по её номеру.
- Пункт 6: время снова свободно.
- Пункт 0: выйти; при следующем запуске история отмены сохранится.

## Правила и границы прототипа

- Один мастер работает с 10:00 до 20:00, длительность — целое число часов.
- Интервал `[начало, конец)` включает начало и не включает конец:
  записи 12:00–14:00 и 14:00–15:00 совместимы.
- Разные услуги одного мастера также не могут пересекаться.
- Запись на прошедшую дату запрещена. Как в ПР1, проверяется календарная
  дата, а не прошедшее время внутри сегодняшнего дня.
- Цена неотрицательная и конечная, длительность 1–10 часов, имя непустое.
- Отмена меняет статус, а не удаляет запись; её ID не используется повторно.
- Длительность и итоговая цена фиксируются в самой записи.
- Прототип рассчитан на один запущенный экземпляр; совместное редактирование
  файлов несколькими процессами не поддерживается.

## Формат хранения

Все файлы — массивы JSON-объектов, кодировка UTF-8. В памяти услуги
индексируются целыми ID, при сохранении записываются списком.

`services.json`:

```json
[{"id": 1, "name": "Мужская стрижка", "price": 1500.0, "duration": 1}]
```

Пример записи `bookings.json` (в исходных данных список пуст):

```json
[{
  "id": 1, "service_id": 1, "client_name": "Анна",
  "date": "2030-01-10", "start_hour": 14, "duration": 1,
  "is_student": true, "price": 1350.0, "status": "active"
}]
```

Статус: `active` или `cancelled`. Даты — ISO `ГГГГ-ММ-ДД`.
Чтение проверяет типы, ID, ссылки на услуги, рабочие часы и пересечения.
Повреждённый файл не подменяется пустым: программа выводит ошибку и
завершается с кодом 1, оставляя данные для исправления.
Отсутствующий файл считается пустым. Запись использует временный файл
и замену исходного после успешной сериализации. При ошибке сохранения
действие отклоняется, состояние в памяти не меняется.

## Проверка

```bash
python -m pytest -q
python -m flake8
```

Тесты используют временные файлы и не меняют данные из `data/`.
Проверяются все пункты меню, повторный запуск, конфликты времени,
граничные часы, скидка, отмена, поиск, сортировка, генератор,
повреждённые JSON и сбой записи. Успешный flake8 не выводит сообщений.

## Упражнение «Холодильник»

Локальное решение требований раздела 5.2 PDF: продукты, партии,
целое и дробное количество, сроки годности, добавление и вывод содержимого.
В памяти используется словарь `название -> список партий`.
Функции `add`, `find`, `get_amount`, `get_expired`, `load_goods`, `save_goods`
находятся в `fridge/inventory.py`.

```bash
python -m fridge add "Молоко" 1.5 --expires 2030-01-10
python -m fridge add "Соль" 1
python -m fridge list
python -m fridge list --query мол
python -m fridge expired --days 2
```

Для отдельного файла: `python -m fridge --file ./my-fridge.json list`.
Продукты нормализуются к нижнему регистру, каждая партия хранится отдельно.
`expired` включает партии со сроком до выбранного дня включительно;
партии без срока годности в этот список не входят. Единица количества
выбирается пользователем и должна быть одинаковой для одного продукта.

Это локальное учебное решение по PDF, а не подтверждение прохождения
автопроверки Яндекс Практикума. Полные условия платформы не предоставлены,
поэтому совместимость с её интерфейсом проверки не заявляется.
